## 🚀 Overview

This is the personal portfolio of **Md Rifat Hossen** — Full-Stack Developer & IEEE Published Researcher. Built with the latest Next.js App Router, React 19, and Tailwind CSS, it showcases projects, blogs, research, skills, and more in a modern, responsive design.

## ✨ Features

- Modern, responsive UI with dark mode
- Projects, research, certifications, and blog sections
- Admin dashboard and login (demo)
- Contact form (EmailJS integration)
- Animated hero, skills, and stats
- SEO optimized and ready for Vercel deployment

## 🛠️ Tech Stack

- [Next.js 16](https://nextjs.org/)
- [React 19](https://react.dev/)
- [Tailwind CSS 4](https://tailwindcss.com/)
- TypeScript
- EmailJS (for contact form)
- Lucide React Icons

## 📁 Folder Structure

```
app/            # Next.js App Router pages
components/     # UI and section components
lib/            # Data and types
public/         # Static assets (images, CV, etc.)
styles/         # Global and Tailwind styles
providers/      # Context providers
```

## 🚦 Getting Started

1. **Clone the repo:**
   ```bash
   git clone https://github.com/rifathossain47/portfolio.git
   cd portfolio
   ```
2. **Install dependencies:**
   ```bash
   npm install
   # or
   yarn install
   ```
3. **Run locally:**
   ```bash
   npm run dev
   # or
   yarn dev
   ```
   Open [http://localhost:3000](http://localhost:3000) to view it in your browser.

## 🚀 Deploy on Vercel

1. Push your code to GitHub.
2. Go to [vercel.com](https://vercel.com/) and import your repo.
3. Set up environment variables if needed (e.g., for EmailJS).
4. Click **Deploy** — your portfolio will be live!
